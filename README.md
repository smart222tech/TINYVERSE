# TINYVERSE ✨

**Create. Explore. Grow.**  
A colorful 2D magical-creature island game for children ages 7–10.

## Technology
- Godot 4.4+
- GDScript
- Procedural 2D art for the first prototype
- Local save data
- English, German and Russian interface

## First playable prototype
- Explore a tiny island with a cottage, trees, flowers and a magical egg.
- Hatch the egg to meet a friendly creature.
- Care for your creature and level it up.
- Collect stars and keep progress locally on the device.
- Change the interface language.

## Run locally
Open this repository in Godot 4.4 or newer and run the main scene at `scenes/main.tscn`.

## Android
An Android export preset and GitHub Actions workflow are included. The first APK build must complete successfully before an installable artifact is available.

## Project status
Early playable prototype. Gameplay depth, art assets, accessibility, child-safe UX and Android packaging will be improved iteratively.
